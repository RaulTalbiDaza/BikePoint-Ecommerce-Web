# 🚴 BikePoint

A fictional cycling eCommerce website built with HTML, CSS and JavaScript.

## About
BikePoint simulates a real online store for cycling products. Designed to practice
frontend development and UI/UX skills through a realistic eCommerce experience.

## Features
- Product listings and category navigation
- Shopping cart experience
- Responsive design (mobile, tablet, desktop)
- Modern and clean UI

## Technologies
- HTML5
- CSS3
- JavaScript

## How to run
1. Clone the repository
```bash
git clone https://github.com/RaulTalbiDaza/BikePoint-Ecommerce-Web.git
```
2. Open `index.html` in your browser

No dependencies or server required.
